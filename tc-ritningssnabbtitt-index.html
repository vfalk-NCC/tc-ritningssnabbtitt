🧊 Lägg till i 3D-vy (experimentellt)

Ingen klickbar punktplacering här (Trimbles API kan inte läsa av var man klickar i själva 3D-modellen) — ankaret väljs istället nedan, och reglagen finjusterar därifrån.
Guiden ritas som fyra hörnpunkter i 3D-vyn (inte den riktiga ritningsbilden — Trimbles API kan inte rendera texturer live) så du kan se ungefärligt läge/rotation/lutning INNAN du laddar upp. Ankaret är bounding-boxen för objektet du har markerat i 3D — flytta/rotera det markerade objektet om ankaret hamnar fel. Storleken (bredd/höjd) kommer från kalibreringen (verktyget "Kalibrera"). Efter uppladdning kan du finjustera ytterligare med Trimble Connects egna "Positionsinställningar" i Modeller-panelen. Experimentellt — testat offline, inte mot en riktig Trimble Connect-miljö än.
